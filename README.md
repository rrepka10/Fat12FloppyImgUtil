This is a Windows utility to create and/or modify DOS FAT12 formatted, 1.44 MB (.img, .ima) image files used in various emulators, Windows and Linux.
This program can copy files from Windows to the image file, add, remove, rename, label and manulape image subdirectores.
This is a branch of https://github.com/jxzhn/fat12 with additional features.  This is a Windows Visual Studio C file
This program can be run in interactive mode or command line mode, features differ between modes.  The command line mode can easily create complex images.
